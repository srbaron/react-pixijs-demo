# React 19 + PixiJS 8.X DEMO

## CONCEPTS LEARNED

- React 19, only have used < 18 at the moment. Lots of nice QoL changes.
- PIXI is not a game dev framework, it's a WebGL wrapper and great for interactivity
- overall PIXI philosophy with building "components"
- PIXI is highly performant
- how PIXI renders sprites on the screen

## THINGS IMPLEMENTED IN DEMO

- user input, mouse & keyboard, eventhandling
- WASD movement
- basic player character animation
- collision maps
- basic menu UI
- sprite looping menu animation
- play music and audio
- adding interactable sprites
- ticker to control elements over time
- scene management
- custom PIXI hooks using React
